---
title: AI agents
description: Give coding agents the stable contract and safe implementation boundaries.
---

Point an agent to `/dual_screen_hinge/llms.txt` and the wire contract. Require
it to preserve nullable fields, unknown enum handling, capability checks,
EventChannel sharing, and explicit session lifetime.

Do not ask an agent to infer fold support from device names, reflect into OEM
classes, use private Apple APIs, or drive layout from a continuous angle. Tests
should inject the Dart platform interface and native hinge provider.
